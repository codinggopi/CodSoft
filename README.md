## 🚀 Project 1: CareerConnect – Professional Job Board Portal
**(Level 2 Task 1)**

**CareerConnect** is a fully-featured job board platform designed to connect employers with talented candidates. It provides role-based access, seamless file handling, and a highly responsive user interface.

### 🌟 Key Features
- **Role-Based Dashboards**: Distinct experiences and tools for Candidates, Employers, and Administrators.
- **Advanced Job Management**: Employers can create and manage job postings, while candidates can search, filter, and apply with ease.
- **Cloud Integration**: Leverages **Cloudinary** for secure, high-performance resume (PDF/DOC) and profile picture uploads.
- **Secure Authentication**: Uses robust **JWT** (JSON Web Tokens) and **bcrypt** password hashing.
- **Modern UI/UX**: Built with Vanilla JS, CSS3, and HTML5, featuring smooth transitions, glassmorphism, and a persistent dark mode.

### 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Deployed on **Netlify**)
- **Backend**: Python FastAPI (Deployed on **Vercel**)
- **Database**: PostgreSQL managed via **Supabase**
- **Libraries**: SQLAlchemy, Pydantic, python-jose, passlib, python-multipart

## 🚀 Project 2: QuizSphere – Full Stack Online Quiz Maker
**(Level 2 Task 2)**

**QuizSphere** is an interactive, real-time online quiz maker. It empowers users to build extensive custom quizzes, share them, and track detailed analytics and global leaderboards.

### 🌟 Key Features
- **Dynamic Quiz Builder**: Create detailed quizzes with categories, difficulty settings, dynamic timers, and unlimited MCQs.
- **Interactive Quiz Taking**: Clean UI with a countdown timer, progress tracker, and auto-submission features.
- **Analytics & Leaderboards**: Instant post-quiz scoring, performance grading, and a global Top 10 leaderboard system.
- **Content Discovery**: Browse, search, and filter quizzes across a variety of tech domains and difficulty levels.

### 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Python FastAPI
- **Database**: MySQL (Relational persistence)
- **Libraries**: SQLAlchemy, Pydantic, JWT authentication

- **Repository Folder**: [`/quizsphere`](./quizsphere)
